    Task: Task 3 – KNN Classifier with Iris Dataset

    Objective:

To build a K-Nearest Neighbors (KNN) classification model using the Iris dataset to accurately classify iris flowers into their respective species based on physical features.

Workflow:

    Dataset Loaded using scikit-learn's built-in load_iris() function.

    DataFrame Creation using pandas for easier manipulation.

    Data Preprocessing:

        Standardized features using StandardScaler.

        Split into training and test sets (80/20 ratio).

    Model Training using KNeighborsClassifier from sklearn.neighbors with k=5.

    Prediction on test data.

    Evaluation using confusion matrix and classification report.

    Results:

    Successfully trained a KNN model.

    Achieved good classification accuracy on test data.

    Model performance was evaluated using metrics like accuracy, precision, recall, and F1-score.
